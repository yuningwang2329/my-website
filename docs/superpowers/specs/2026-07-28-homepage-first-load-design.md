# 首页首屏性能优化设计

## 目标

消除首页首次加载时不必要的 MathJax 下载与列表公式排版，同时保留论文详情页的 Markdown 和公式阅读。

## 范围

- 修改 `index.html`：移除 MathJax 配置、外部脚本和 `render()` 后的公式排版调用。
- 保持 `post.html` 不变：继续按需加载 Marked 与 MathJax，渲染单篇论文内容。
- 不改变论文数据格式、筛选、收藏、已读状态和 GitHub Actions 更新流程。

## 验收

- 首页不再请求 `tex-chtml.js`，论文列表能正常显示。
- 论文详情页仍可加载 Markdown，并保留公式排版能力。
- 线上首页、数据文件和详情页均可访问；首页关键资源体积与首次加载时间下降。
