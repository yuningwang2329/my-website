# 手机端内容优先设计

## 目标

让手机访客打开首页后尽快看到最新论文，同时保留桌面端现有的侧栏筛选能力和所有论文订阅功能。

## 范围

- 仅在窄屏幕（最大宽度 768px）调整首页的筛选布局；桌面布局保持不变。
- 首页首屏保留标题和论文列表；文献库、专题、期刊和月份筛选统一收进一个可展开的“筛选文献”控件。
- 控件收起时不占用筛选列表高度；展开后继续使用现有筛选项、计数和“按期刊/按月份”切换。
- 收藏夹、专题筛选、期刊筛选、月份筛选、已读状态和“标为已读”均沿用当前数据与逻辑。
- 论文详情页、订阅数据格式、GitHub Actions 自动更新和桌面端视觉结构不在本次改动范围内。

## 交互与可访问性

- 控件使用原生 `button`，通过 `aria-expanded` 表示展开状态，屏幕阅读器可理解其用途。
- 按钮文案为“筛选文献”；展开后显示“收起筛选”，避免只依赖图标。
- 初始状态保持收起，使手机首屏直接进入论文列表。
- 现有筛选项仍使用其原有点击逻辑；选中筛选后列表即时更新，筛选面板保持可继续调整。

## 实现边界

- 在 `index.html` 增加只服务于手机端的筛选开关和极小的状态函数；不引入框架或新的外部依赖。
- 在 `style.css` 用一个专用的移动端媒体查询控制筛选面板和开关按钮，避免影响桌面侧栏。
- 通过静态测试锁定两项回归：开关按钮及其无障碍属性存在；桌面布局规则继续保留，移动端才隐藏筛选面板。

## 验收标准

- 在 390px 宽的视口中，初始首屏显示“所有文献”和第一组论文，无需先滚过期刊列表。
- 点击“筛选文献”后，文献库、专题、期刊/月份筛选和计数完整可用；再次点击可收起。
- 期刊、月份、专题、收藏和已读操作继续正确过滤或更新论文列表。
- 在桌面宽度下，侧栏默认展开，视觉与现有布局一致。
- 首页性能测试和新增移动端结构测试均通过；本地首页和论文详情页均能正常加载。
